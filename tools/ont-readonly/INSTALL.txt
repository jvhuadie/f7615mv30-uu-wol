中兴光猫只读检测与完整备份工具 v0.6

普通检测（用于反馈）：
1. 电脑连接光猫局域网，双击 ZTE-ONT-readonly-v0.6.exe。
2. 填写实际 Telnet 地址、端口、用户名和密码。默认 192.168.1.1:23、root、Zte521，不保证适用于所有设备；工具不会开启 Telnet 或尝试其他密码。
3. 可选填写机身标签型号和硬件版本，点击「开始只读检测」。共 49 个分组，不写光猫文件、不改自启、不进入容器或控制台、不安装/停服务/重启。
4. 打开结果目录，检查 TXT 的设备摘要、采集覆盖、提示和内容，再提交普通检测 ZIP。
5. 资料收集链接：https://share.fnnas.net/s/a6cea4a86c714bdf87
   网页「请输入您的名字」请填写设备型号（如 F7005MV3、G7615V2），不要填写姓名；不确定时填「型号未知」。不要向此处上传完整备份。

完整备份（仅本人保管，要求光猫 root）：
1. 选择备份范围：文件系统 + 固件 / 仅文件系统归档 / 仅固件原始映像；点击「完整备份导出」。
2. 数据直接流式保存到电脑 PRIVATE-full-backup-* 目录，光猫不生成临时包。可能耗时较长；每接收约 4 MiB 提示进度，可点击「取消备份」。
3. 文件系统生成 filesystem.tar，包含原始配置、账号、密钥和绑定资料。排除虚拟/运行时挂载与外接介质，不跟随符号链接；清单记录排除项。默认 8 GiB 上限，超限保留部分结果。
4. 固件模式读取 MTD 逻辑块设备；若存在明确 whole/full flash 优先导出它，否则逐分区。无 MTD 时尝试 eMMC 主设备与 boot0/boot1，不读取 USB/SD 的 sdX。需可读节点和足够电脑磁盘空间，总量上限 64 GiB。
5. 导出后查看 backup-manifest.json、flash-layout.json 或 filesystem-excludes.json。只有通过校验的块设备才成为 .img；读取中断、源变化等保留 .partial，不能当成完整映像。
6. 完整备份包含未脱敏敏感资料，请勿上传公开仓库、Issue 或适配资料收集页。完成后窗口会禁用「提交适配资料」，再次运行普通检测后恢复。

备份的重要边界：
- 运行中读取没有冻结文件系统或一致性快照，可能出现文件/分区变化；不能保证可恢复。tar 不是逐文件远端哈希验证的静态快照。
- MTD/eMMC 是逻辑原始数据，不包含 NAND OOB/ECC、eMMC RPMB 等特殊区域；不是厂商升级包，不可直接作为可刷回固件。
- 不提供刷写、恢复或断点续传。缺工具、读取受限、磁盘不足和不支持的布局会失败；查看清单，不能只凭文件存在判断成功。
- Telnet 本身不加密，请只在可信局域网使用。本工具不会自动上传报告或备份；源设备可能记录登录或文件读取。

采集范围与判断：
普通检测覆盖身份/版本、运行库、启动机制、CU/UPT/Java/OSGi、SAF 位置、容器命名空间、持久化分区、网络策略等。只查询 saf 位置，不执行 saf console 或尝试控制台密码。自定义 rc.local/run.sh 仅记录元数据，不读取内容。
设备树 ZTE 133 是板级描述，构建日期不是产品固件版本；均与型号线索分开显示。普通报告 schemaVersion 为 3，记录逐组耗时、提示、截断和未完成分组。
COMPLETE 表示所有分组返回，不表示每条子命令成功或设备已兼容。目录/脚本/字符串输出有限制，缺失或未匹配不能证明不存在。未读取账号数据库、绑定、原始程序/固件的承诺仅适用于普通检测模式。

Windows 需要 PowerShell 5.1 和 .NET Framework，无需 Python、SDK 或 Windows 管理员权限。光猫端权限另计。
v0.6 新增采集和备份尚未进行实机验收，离线/模拟测试不代表所有型号均可导出。
