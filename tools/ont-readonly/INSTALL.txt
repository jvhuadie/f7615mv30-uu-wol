中兴光猫只读检测工具 v0.5（Windows 单文件 EXE）

运行前：
1. 电脑用网线或 Wi-Fi 连接待检测光猫的局域网。
2. 需要已经具有 Telnet 登录权限，本工具不会开启 Telnet、破解密码或修改配置。
3. 支持 Windows PowerShell 5.1 和 .NET Framework 的 Windows 电脑；无需安装 Python，不需要管理员运行。

怎么运行：
1. 下载并双击 ZTE-ONT-readonly-v0.5.exe，不需要解压或另外放脚本。
2. 默认 IP 192.168.1.1、端口 23、用户名 root、密码 Zte521；可以直接检测，也可以按实际情况修改。这是预置值，不保证所有型号、运营商固件使用相同密码。
3. 选择电脑上的保存目录，点击“开始只读检测”。通常几十秒，个别命令可能等待超时；保持网络连接，等到提示完成或失败后再关闭。
4. 本工具只读取系统与启动元数据，不会上传或运行安装脚本，不会安装 UU、写光猫文件、改自启、停进程或重启光猫。系统本身可能记录 Telnet 登录行为。

怎么发回结果：
1. 点击“打开结果目录”，先打开同名 TXT 检查内容。
2. 点击窗口「提交适配资料」或打开 https://share.fnnas.net/s/a6cea4a86c714bdf87 。网页「请输入您的名字」请填写机身标签上的设备型号（如 F7005MV3、G7615V2），不要填写姓名；型号不明时填写「型号未知」。选择 ZTE-型号-架构-readonly-日期时间.zip 原文件上传，无需截图或解压重打包。
3. ZIP 内有 report.txt 和 report.json。失败或中断也会尽量保存结果，请一并反馈窗口上的状态。
4. 报告自动隐藏常见 IP、MAC、密码类字段及当前输入密码；没有采集光猫账号配置、固件镜像、UU 绑定文件或完整进程命令行。自动隐藏并非绝对保证，发送前请自行检查，不要公开上传到论坛或仓库。本工具不会自动联网上传报告。
5. 如果没有生成 ZIP，直接反馈提示文字；不要发送 Telnet 密码或光猫配置备份。

检测结果用于研究架构、库兼容性、分区和启动入口，不代表报告对应型号已经支持安装。G7615V2、F7005MV3 等新增型号仍需分别验收，请勿用 F7615MV30 安装器绕过固件限制。

v0.2 补充说明：改为通用型号名称；修复时间和 inittab 字段被误认为 IPv6 的脱敏问题；增加网络及驱动启动脚本、候选回调引用的只读采集。检测阶段可以离线运行，UU 联网与远程唤醒测试则需要设备具备实际外网连接。


v0.3：补查主启动脚本第 161–1000 行、其他原厂服务脚本、Java/插件目录元数据、Java 启动脚本、服务权限与固定二进制中的路径引用、调度器元数据。共 21 个分组。只读取脚本，不执行其中的命令；不读取插件数据库、任务内容或账号配置。每项输出设有行数边界，未显示的部分不能据此判断不存在。仍无需连接外网或重启。


v0.4：共 26 个分组。增加原厂 Felix 框架启动属性白名单、插件目录元数据、原生程序插件启动字符串及 BusyBox 内置调度命令检查。仅读取框架文件中的指定属性，不读取运营商账号配置、插件缓存内容或安全策略；不执行任何候选启动入口。属性续行暂不采集，白名单未命中不能视为未配置。引用和目录存在都不代表支持自启。


v0.5：共 27 个采集分组。新增设备身份摘要：系统主机名、设备树型号线索、架构、软件版本与 /bin/cspd 完整指纹。主机名仅作为待核实线索；来源不一致或与用户填写型号不符时显示冲突。无法识别时明确标记型号未知。
窗口可选填写机身标签型号与硬件版本，仅填写这些产品信息，不要填写序列号或账号。用户填写信息与自动线索分别保存。ZIP/TXT 文件名包含型号线索和架构，冲突及用户填写会明确标记；报告顶部与 JSON identity 字段保存来源和状态。
明确 VERSION、VERSION_ID、SOFTWARE_VERSION 字段中的点分版本号保留，其他位置继续隐藏常见地址。软件版本来自系统文件，可能是系统构建版本，仍需与管理页面/机身标签核对。检测完成会在窗口显示设备摘要；识别出型号不代表已适配。
