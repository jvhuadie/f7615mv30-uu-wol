中兴光猫只读检测工具 v0.7.0

1. 电脑连接待检测光猫的局域网，双击 ZTE-ONT-readonly-v0.7.0.exe。
2. 填写实际 Telnet 地址、端口、用户名与密码。默认 192.168.1.1:23、root、Zte521，可修改；不保证适用于所有型号，不自动开启 Telnet 或尝试其他密码。
3. 可选填写机身标签型号与硬件版本，不要填写序列号。点击「开始只读检测」。
4. 等待完成或失败提示，打开结果目录，检查同名 TXT 的设备摘要、采集覆盖、提示与内容。
5. 通过「提交适配资料」按钮或链接 https://share.fnnas.net/s/a6cea4a86c714bdf87 上传普通报告 ZIP 原文件。
   网页「请输入您的名字」填写设备型号，例如 G7615V2、F7005MV3；不要填姓名，不明时填写「型号未知」。

本版本只提供 56 项通用只读采集，不含完整备份功能。不导出完整文件系统、固件或程序，不读取账号数据库、UU 绑定文件、进程参数/环境变量；自定义 rc.local/run.sh 仅采集元数据。
采集不上传脚本、不写光猫文件、不修改自启、不进入 saf 或容器、不安装或停止服务、不重启，不发起外网测试。

报告保存在电脑，不会自动上传。自动隐藏常见 IP/MAC、敏感字段及当前输入密码，发送前仍应检查。不要公开配置备份、账号密码、序列号、密钥或绑定资料。
设备树 ZTE 133 是板级描述，构建日期不是产品固件版本；报告分别显示型号来源、板级描述和构建时间。
COMPLETE 只表示所有分组返回，不能证明每条命令成功或设备已经适配。输出有范围限制，缺失不能直接判断不存在。失败/中断时也请反馈部分 ZIP；无需截图或解压重打包。

Windows 需 PowerShell 5.1 与 .NET Framework，无需 Python 或 Windows 管理员权限。Telnet 不加密，仅在可信局域网使用。设备可能记录登录行为。
v0.7.0 的 56 项扩展采集仍待实机验证；离线/模拟测试不代表所有型号均已验证。

新增创维及通用厂商 OSGi 采集：/usr/local/osgi 与 /usr/data 候选目录、Felix 存储和自动加载字段、Java 原生执行权限白名单、插件登记元数据、skyage.sh 启动线索及缺命令检查。共 56 组。
不执行 getid/sendcmd/skyage.sh，不安装插件或更改权限，不导出完整配置。请在型号备注填写机身型号，例如 SK-D847N；skyworth 主机名不能确认具体型号。
