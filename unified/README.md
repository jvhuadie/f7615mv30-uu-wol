# 统一版运行资源与源码

Windows 源码版本：v1.1.0-rc6。新增限定固件的 [G7615V2 实验适配](../docs/G7615V2.md)，用户反馈本轮测试成功，重启自启待验证。稳定发行版仍为 v1.0.0。支持已验证固件的 F7615MV30 与 F7005MV3，自动识别后选择对应安装和管理流程。

**F7615 安装完成后必须手动重启光猫**，再检查服务、App 在线和远程开机；工具不会自动重启。首次运行可能停止的问题尚未定位，重启后已验证恢复。
