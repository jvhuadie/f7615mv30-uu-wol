F7615MV30 UU 远程开机助手 v0.6.1 — 服务管理实验版
GitHub 实验版；光猫端仍为 v0.3，已安装者无需重装。

一、直接使用单个 EXE
1. 下载 f7615mv30-uu-wol-v0.6.1.exe，直接双击；不需要 ZIP、旁边的脚本或 tools 文件夹。
2. 默认 IP 192.168.1.1、Telnet 用户名 root、密码 Zte521，密码隐藏显示；可在窗口手动覆盖。
3. 先点击“检查状态”，查看版本、自启、云连接及日志输出状态。
4. 只有需要安装或升级时，才点击“安装 / 升级”。已安装光猫端 v0.3 的用户无需重装。
5. 可点击“使用说明”打开本说明。执行期间等待操作完成，再关闭窗口。

服务管理按钮
启用自启：设置光猫重启后运行 UU，不立即启动当前服务。
停用自启：关闭后续自启，不立即停止当前服务。
启动服务：启动已安装的 UU，保留原自启开关。
停止服务：停止 UU，保留原自启开关；停止期间这台光猫不能协助远程开机。
卸载服务：弹出两种选择，默认“保留数据”。
  保留数据：停止 UU、取消自启并恢复安装前入口；保留程序、绑定及备份，可点击“恢复服务”。
  完全卸载：需勾选删除确认。删除光猫上的本项目安装目录（含 SN、UUID、uu.conf）、项目日志、已识别的项目备份、旧副本、早期测试目录和本项目的原探针入口。电脑上的备份、UU App 中的设备记录保留。再次使用需重新安装并绑定，不能直接点击“恢复服务”。
  预检检查固件与脚本指纹、目录真实路径、符号链接、嵌套挂载、已知备份格式和入口状态。未知备份或其他程序修改入口时拒绝操作。若删除阶段断线或失败，可能已部分清理，应先检查状态，不要反复执行。
恢复服务：仅恢复本项目保留的已卸载服务，重新启用自启并启动原程序，不重新下载或重新绑定。自启入口已被其他程序修改时拒绝覆盖；启动失败时尝试回退至卸载状态。
复制记录：复制窗口中的操作记录，不复制连接密码输入框。

停止／卸载会弹出明确说明，默认选择取消。所有管理操作需核对固件指纹、未修改的 v0.3 控制脚本与回调脚本，并核对操作后的状态；不匹配、管理锁占用或结果不明时不会自动重试。断线后先点击检查状态。只读窗口禁用管理按钮，后台也拒绝只读模式执行更改。
这里的“自启”针对光猫，不会设置 Windows 开机启动。只需使用远程开机时，保持光猫自启启用且服务在线即可；不要为了测试按钮而停止或卸载正在使用的服务。
用户已在参考光猫上实际执行完全卸载、重新安装和启动，反馈重启测试正常；其他管理组合及长期稳定性尚未全面验收。

二、适用条件与单文件工作方式
只适用于已验证的 ZXHN F7615MV30 aarch64 固件，需具备 root Telnet 权限。
需要 Windows 自带的 Windows PowerShell 5.1／.NET Framework；无需额外安装 Python 或开发 SDK。
默认值只是预置登录信息，不代表其他光猫的通用密码；工具不会修改光猫密码。
EXE 内嵌窗口、安装脚本、说明和默认配置。启动时释放到当前用户专用的随机临时目录，逐文件校验后执行；正常退出清理自己的目录。强制结束进程时可能残留临时目录。
EXE 不读取旁边的 Gui.ps1 或 defaults.json；手动输入的密码只在进程内存中使用，不写入临时配置、日志或进程参数。公开默认密码没有加密或隐藏于资源之外。
单文件版临时目录中的文件不需要手动修改。需要定制预置配置时，请修改源码并重新构建。
状态检查只读，不上传或执行安装脚本，不重启 UU 或光猫；绑定和实际开机效果仍需在 App 中确认。
本工具没有手机／电脑游戏加速适配功能。

三、绑定自己的 UU 账号
干净安装：在 UU 主机加速器的“路由器加速 → 合作款路由器”中添加设备，可能显示 OpenWrt。
电脑 UU 远程登录同一账号，在“远程开机配置／开始协助”中关联辅助设备，按向导设置主板及有线网卡 WOL。
界面名称可能随客户端版本变化；电脑需保持接电及有线网络连接。

已有本项目测试安装：按以下优先级恢复本机 .sn、.uuplugin_uuid 和 uu.conf：
/tmp/uu-f7615-test/files
/usr/plugin/uu-wol-f7615/files（旧版目录）
/usr/plugin/uu-wol-backup/working-backup.tar.gz（本机工作备份）
不要删除原设备并重新添加，以掩盖重启后绑定丢失。

已安装 v0.3 的用户：打开单文件 EXE 点击“检查状态”即可，不必再次安装。
已安装 v0.2 的用户：先点击“安装 / 升级”升级至光猫端 v0.3，无需卸载或重新绑定；新的管理按钮仅接受已验证的 v0.3 脚本。
升级只替换脚本，保留程序、绑定文件、自启开关和卸载恢复信息，不重新下载网易程序。
会短暂重启 UU 进程，不会重启光猫；若原来停用自启且程序停止，升级后保持停止。
原脚本备份到安装目录 backup-before-v0.3/，新版启动失败会尝试恢复旧脚本和原进程。
旧脚本被手动修改时拒绝覆盖。自动工具应显示光猫端版本 0.3、自启与云连接状态；日志输出转向 /dev/null 时可能没有持续运行的日志管道。
备用模式正常升级显示 UPGRADE_COMPLETE v0.3。最后在 App 确认原设备在线。

四、验证重启自启和远程开机
1. 光猫正常重启，等网络恢复后再等约一分钟。不要手动执行 start。
2. root Telnet 执行：
sh /usr/plugin/uu-wol-f7615/control.sh status
cat /tmp/uu-f7615-boot.log
3. 应看到 AUTOSTART_ENABLED、uuplugin 及 xuplugin-guardian 进程、16000 ESTABLISHED 连接。
   App 中原设备应自动在线，不需要重新绑定。
4. 电脑正常关机，保持电源和网线，等约 30 秒。
5. 手机关闭 Wi-Fi，使用移动数据，在 UU 远程中开机，确认电脑实际启动并恢复在线。
三项都通过才算完整验收：插件自动运行、原绑定保留、手机流量实际唤醒。
v0.2 参考样本已通过上述完整流程；v0.3 升级后的样本和其他新设备仍须独立测试。

五、管理和卸载
sh /usr/plugin/uu-wol-f7615/control.sh status
sh /usr/plugin/uu-wol-f7615/control.sh log
sh /usr/plugin/uu-wol-f7615/control.sh stop
sh /usr/plugin/uu-wol-f7615/control.sh start
sh /usr/plugin/uu-wol-f7615/control.sh disable
sh /usr/plugin/uu-wol-f7615/control.sh enable
sh /usr/plugin/uu-wol-f7615/control.sh uninstall
disable 只停用后续自启；若要完全停止，先 disable 再 stop。
上面的命令行 uninstall 为“保留数据”卸载。需要完全删除时使用窗口中的“卸载服务 → 完全卸载”，勾选确认。
入口若被其他工具修改会停止卸载。不要盲删 /var/run/uuplugin.pid。

日志限额：v0.3 的标准输出和错误输出通过独立管道写入 /tmp 内存盘。
uu-f7615-service.log 和 uu-f7615-service.log.previous 各最多 256 KiB，合计最多 512 KiB。
只保留一份 previous；按输入块轮转，短读取可能提前轮转，单行可能跨文件。
日志不写入闪存，重启后清空；轮转不重启 UU，也不向 UU 设置文件大小信号限制。
没有输出时阻塞等待，不做定时轮询。写入失败时继续消费输出，避免关闭管道干扰程序。
停止后最后一段可能位于 previous，log 命令会显示两份文件。
限额不覆盖闭源程序自行创建的其他日志；自启结果 boot.log 仍每次回调覆盖。
查看占用：
ls -l /tmp/uu-f7615-*.log*
df -k /tmp /usr/plugin

六、原理与边界
使用 /wlan/wifi_debug.sh 的无线配置回调，在后台延迟 20 秒启动。
程序和绑定保存于 /usr/plugin/uu-wol-f7615，Telnet 断开后仍可运行。
不修改根文件系统、osgi.img、WAN/VLAN/TR069；不自动开启游戏加速或升级网易程序。
网易固定版本 openwrt-aarch64 v14.10.6 在安装时下载，并强制验证 SHA-256：
590006073430b2b1ca441615482e4eef2d7bce0cebc455f486a76c9da60569e5
由于参考光猫 CA 验证失败，固定下载使用 curl -k；独立哈希校验失败则停止。
仓库和安装包附带明确列出的默认登录值，不附带厂商二进制、个人绑定文件或设备身份。
参考设备已实机验证远程唤醒、自启、云连接及 v0.3 独立日志轮转；本轮重装后的重启测试由用户反馈通过。
保留绑定、失败恢复等升级分支有模拟测试覆盖；本轮新增管理流程的实机使用情况见上文，不将单台结果扩展为其他固件兼容。
启停和卸载等部分流程仅完成模拟验证，长期稳定性、多轮重启和其他固件尚未验证。
详细记录见包内 docs/VALIDATION.md。项目不是网易或中兴官方产品。

七、遇到问题与隐私
自动连接失败先查光猫 IP、Telnet 开启情况、用户名和密码；备用模式再查电脑 IP 及防火墙提示。
自动安装期间连接中断时，结果可能未知，先运行 Check.cmd 检查，不要重复安装。
固件指纹不同或存在未知启动脚本时，不要绕过检查或强行覆盖。
插件离线时先查看 status、log 和自启日志；插件在线但电脑不启动时检查 WOL 设置。
报错可到仓库 Issues 反馈，先打码账号、令牌、设备标识和个人网络地址。
请勿公开光猫安装目录、工作备份、固件导出包或 UU 绑定文件。

修复说明：v0.5 修复 v0.4 在填写局域网 IP 时的校验错误。错误发生在连接光猫前，不影响已安装的光猫端。重新下载并解压新版，先运行 Check.cmd 即可。

回车默认值：光猫 IP 为 192.168.1.1，用户名为 root，Telnet 密码为 Zte521。图形窗口信息已预填，直接点击检查即可；手动输入可覆盖。默认密码明文内嵌于 EXE 的配置资源。单文件版在窗口手动覆盖；源码版可编辑 defaults.json 后重新构建。此值仅为预置登录信息，不代表其他光猫的通用密码；工具不会修改光猫密码。密码提示保持隐藏，不自动重试其他密码。

日志检查提示：检测到日志管道时显示运行中；未检测到时，只读检查本项目 UU 主进程的标准输出和错误输出。均为 /dev/null 时说明当前不写入管道日志，不判作故障；未找到主进程或无法确认输出去向时仍提示检查。云连接单独显示，不以日志状态代替远程开机验收。此检查不修改光猫端脚本，不重启服务，也不据此断言日志进程退出原因。

日志管道排查补充（2026-10-25）：
“日志管道运行中”与“UU 主进程输出为 /dev/null”可以同时成立，不能据此判定故障。
参考 F7615MV30 重启后实测：uuplugin 主进程输出为 /dev/null；xuplugin-guardian 的标准输出和错误输出仍连接日志管道写端；log-writer.sh 及 dd 子进程持有同一管道读端，休眠等待新数据。
实际连接为 guardian 输出 → 日志管道 → log-writer / dd → /tmp 日志。主进程与 guardian 的输出去向不同。
日志当前仅 26 字节且不增长，说明本次观察期间没有新增输出；不代表接收器卡死，也不保证持续收集主进程运行日志。
服务、自启和云连接正常时无需为此重启、重装、修改进程输出或关闭接收器，保持现有日志轮转即可。若服务停止、云连接断开或日志写入错误，再核对进程、管道两端和日志；不要只凭 PID 文件或主进程输出去向判断故障。远程开机仍需实际测试。
