## 安装与使用

1. 在统一工具中填写光猫实际地址和 Telnet 凭据。创维这台使用 root / Pon521；界面原有密码可能仍为中兴常见值，需要手动填写，工具不轮流猜密码。
2. 点击“检查状态”，再点击“安装 / 升级”。仅放行匹配参考指纹、Java 身份、存储和运行条件的设备；不覆盖已有安装或未知残留。
3. 大文件优先局域网 HTTP 直传并校验；连接失败回退 Telnet。创维的备用传输采用较短命令行。绑定恢复文件仅走已有 Telnet，不通过临时 HTTP 服务提供。
4. 服务启动后在 UU App 中添加/确认设备，验证移动数据远程开机。每次新安装仍需自行确认重启自启。参考设备本轮在新启动约 268 秒时确认 UU、guardian 和云端 TCP 恢复，期间没有手动启动本项目；这是一次观察时间，不是固定启动耗时保证。
5. 创维“启动服务/启用自启”联动，“停止服务/停用自启”联动。“保留绑定卸载”停用插件、保留程序及绑定并撤销启动辅助程序的 setuid 位；“恢复服务”重新启用。
6. “完整卸载”先把三个小绑定文件以 JSON 备份到电脑文档目录 `SK-D847N-UU-WOL`，再撤销辅助程序权限、移除自有插件登记和目录。重新安装时可在“型号选项”中选择该 JSON，或通过命令行 `-BindingArchive` 传入。备份含绑定身份，保留在本地，不要上传公开 Issue。

`sismac` 是参数工具，本项目不通过它改参数。插件操作使用原厂 `sidbg 74 osgid`，根据本项目唯一登记和实际状态回查结果；启动、停止和卸载传插件名称，不能只信帮助中的 Bundle ID 文案或命令返回码。

## 权限与文件范围

不修改原厂配置、Java 策略、原厂 JAR、LAN 地址或路由；不安装全局 shell 自启脚本，不修改老化测试 `skyage.sh`。本项目持久文件位于 `/usr/data/uu-wol-skd847n`，OSGi 数据由原厂分配在 `/usr/data/o_ins/felix-cache/bundle*/data`。

由于参考 JFFS2 不支持 `setcap`，使用不足 1 KiB 的固定用途启动辅助程序：它由 root 持有并设置 setuid 位，只接受 UID 107，校验 root 持有的固定目录/程序，仅创建或核对固定 PID 文件，然后清除附加组、永久降为 UID 107/GID 110，仅保留 `CAP_NET_RAW`，通过已打开的文件描述符执行固定 UU 程序。没有 shell、任意执行路径、用户命令参数或 `CAP_NET_ADMIN`；UU 和 guardian 的实际进程 UID 与能力已在启动及重启后核对。

源代码见 `unified/profiles/skd847n/src/launch-uu.S`。`src/build_native.py` 使用 keystone-engine 可重现并核对固定二进制；Java 激活器为 `src/local/ont/skd847n/Activator.java`，使用 Java 8 API 和 OSGi 编译接口。重新编译服务包时需同步更新运行清单及 control.sh 中的固定摘要。

状态中的重启验收标记仅在实际验收后写入，绑定到本次启动标识和程序摘要；新安装不会自动获得“本次重启已验证”。普通自启开关、进程存在、云端 TCP 和用户 App 验收是不同状态。
