## 使用方法

1. 下载单文件 EXE，直接双击；安装包 ZIP 内含同一 EXE、中文说明、验证记录和校验文件。
2. 填写目标光猫的实际管理地址，点击 **检查状态**。工具自动识别填写的地址，不扫描局域网。
3. 首次安装时点击 **安装 / 升级**，无需手动选择型号。F7005 不覆盖已有安装，已经安装时先检查状态。
4. **F7615 安装完成后先手动重启光猫**，网络恢复后检查服务和 App 在线；F7005 按使用说明验证重启自启。
5. 全新安装需要绑定并配置远程开机；保留身份恢复时确认原设备在线。最后用手机移动数据测试关机唤醒。

| 连接项 | 默认值 |
|---|---|
| 光猫 IP | `192.168.1.1`，按实际地址修改 |
| Telnet 用户名 | `root` |
| Telnet 密码 | `Zte521`，隐藏显示、可修改 |
| Telnet 端口 | `23`，统一版当前固定此端口 |

需要已有 root Telnet 权限；工具不负责解锁。默认登录值不保证适用于所有设备，清空 IP、用户名或密码时使用默认值，不会修改光猫密码。Windows 需要 PowerShell 5.1 / .NET Framework，无需另装 Python 或 SDK。

## 服务管理与卸载

| 操作 | F7615MV30 | F7005MV3 |
|---|---|---|
| 启动 / 停止服务 | 不改变自启开关 | 与自启同时开启 / 关闭 |
| 启用 / 停用自启 | 不立即启停服务 | 与服务启动 / 停止联动 |
| 保留数据卸载 | 保留光猫上的可恢复程序及绑定 | 先备份绑定到电脑，再清理光猫端安装 |
| 完全卸载 | 按原流程清理项目程序、绑定和已识别备份 | 解除文件保护、撤销授权，再清理插件、进程、PID 和安装目录 |
| 恢复服务 | 恢复光猫上保留的安装 | 选择绑定 TGZ 后按安装流程恢复 |

电脑上已有备份与 UU App 设备记录不会被删除。F7005 的绑定备份和框架备份保存到实际 Windows 用户的“文档/F7005MV3-UU-WOL”，不依赖特定电脑用户名。备份是恢复参考，不要直接覆盖运行中的插件缓存。

“型号选项”包含 F7005 的绑定 TGZ 恢复、仅测试 PID 和切换到 UU 服务；这些选项不能用于 F7615。操作中断时先检查状态，不要反复安装或卸载。

## F7005 的权限与文件保护

UU 以普通插件用户运行，仅 `CAP_NET_RAW`；固定用途 PID 准备程序仅 `CAP_DAC_OVERRIDE`，只创建或校验 `/var/run/uuplugin.pid` 后退出。不授予 UU root 或 `CAP_NET_ADMIN`，不修改原厂 Java 权限规则、启动脚本或 LAN 地址。

原厂开机脚本递归调整 `/usr/plugin` 属主，会清除文件 capability。本方案仅对两份自有程序设置 immutable 文件保护，保留授权；对这两个文件的 chown 可能提示 `Operation not permitted`，已验证的启动脚本会继续执行。卸载时先解除保护。

**F7005 必须用本工具卸载，不要直接从原厂插件管理页面删除**，否则原厂删除流程无法清理受保护的程序。自动修复仅针对已验证且运行异常的原始 Andlink，其余固件停止；修复前备份，并提供超时回退及独立回退脚本。

- 统一工具源码和运行资源位于 [`unified/`](unified/)；仓库根目录的旧 F7615 入口保留供兼容和历史查阅。

EXE 启动时将白名单资源释放到当前用户专用临时目录，逐项核对 SHA-256，正常退出清理自己的目录。F7005 运行资源内含已校验的 UU 程序，F7615 保持原来的光猫端下载流程。默认密码是可提取的公开内嵌配置；手动输入的密码仅在内存中使用，不写入记录或命令行参数。Telnet 不加密，请在可信局域网内使用。

在线文档会补充后续验收结果；已发布 EXE／ZIP 内的说明保留发布时版本，最新步骤以本仓库为准。

发行包不含设备绑定身份、原始固件导出、私有框架备份或个人配置。不要公开 `.sn`、`.uuplugin_uuid`、`uu.conf` 或设备备份。
